## 5. Architectural Strategy for the Portfolio

1. **Frontend (`/client`):**
   - Single-Page Application (SPA) built with React 19 / Vite.
   - Tailwind CSS for sleek dark/light design system with custom CSS variables.
   - Framer Motion for high-precision micro-animations.
   - IconSpace integrated SVG icon set alongside Lucide React for consistent, energetic iconography.
   - Full filtering for projects: All, Full Stack, FinTech & AI, Security & Systems, Frontend.
   - Interactive project inspection modals with live GitHub links, feature breakdowns, and tech tags.
2. **Backend (`/server`):**
   - Express REST API with security middleware (Helmet, CORS, Express-Rate-Limit).
   - MongoDB + Mongoose ODM for saving contact form messages.
   - Binary resume routes (`/api/resume/pdf` and `/api/resume/docx`) serving verified resume files.
   - Health check endpoint (`/api/health`) returning operational status.
   - Graceful offline MongoDB handling and input sanitization.
3. **Automated Testing & QA:**
   - Supertest integration tests for backend endpoints.
   - In-memory MongoDB testing to guarantee Mongoose persistence.
   - Frontend production build verification (`vite build`).
